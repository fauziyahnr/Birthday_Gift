# Birthday_Gift

Sebuah website hadiah ulang tahun interaktif yang estetik, romantis, dan responsif.

Fitur di Section 1:
- Halaman Pembuka dengan kotak hadiah yang bisa diklik untuk membuka dan menampilkan confetti serta nama "SEPTIAN DWI WAHYU".
- Ucapan/hitung mundur elegan dengan efek glassmorphism.
- Musik latar dengan tombol Play/Pause (placeholder audio URL; ganti dengan file Anda).

Fitur di Section 2:
- Galeri foto kenangan dengan hover effect dan modal zoom.
- Pesan/Surat Spesial bergaya surat cinta.
- Efek love jatuh di latar belakang menggunakan CSS/JS murni.

Cara gunakan / kustomisasi cepat:
1. Buka `index.html` dan edit teks, pesan, atau gambar.
2. Untuk mengganti audio, edit atribut `src` di `<audio id="bgAudio">`.
3. Untuk menyesuaikan tanggal hitung mundur, buka `assets/scripts.js` dan ubah variabel `birthMonth` dan `birthDay` atau langsung set `finalDate` ke tanggal tertentu.
4. Ganti gambar galeri ke gambar Anda (atau tambahkan lebih banyak elemen `<img>` di bagian Galeri).

Deploy: file ini siap di-deploy ke layanan statis seperti GitHub Pages, Netlify, atau Vercel. Cukup publish branch `main`.
